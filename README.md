# 🏆 Alyssa's Sports Analytics Website

A live sports dashboard built with Python and Flask, pulling real-time data from the ESPN API. Covers PGA, NBA, NFL, and MLB — including live scores, season standings, and the latest news for each sport.

🌐 **[View the Live Site](https://alyssas-sports-analytics.onrender.com)**

---

## Features

- ⛳ **PGA** — Live tournament leaderboard with top 5 players and scores
- 🏀 **NBA** — Today's games and season standings with win/loss records
- 🏈 **NFL** — 2024 season standings by conference
- ⚾ **MLB** — Today's games and season standings, with special highlighting for the San Diego Padres
- 📰 **Top Sports News** — Latest headlines from ESPN for all four sports

---

## Tech Stack

- **Backend:** Python, Flask, Flask-CORS
- **Frontend:** HTML, CSS, JavaScript
- **Data:** ESPN public API
- **Hosting:** Render

---

## How It Works

The Flask backend serves the frontend page. All sports data is fetched live from ESPN's public API directly in the browser — no database needed. Every time you click a button, it pulls the most current data available.
